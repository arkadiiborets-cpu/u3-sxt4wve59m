AXAL · Заняття 3 · за документацією Claude Code: subagents

Мысль: в чате вы работаете с одним собеседником, в Code — с исполнителем, который сам раздаёт части задачи помощникам. Explore и Plan встроены, Claude зовёт их сам. Свои субагенты — файл в .claude/agents с описанием, когда их звать: например рецензент автоматизаций по пяти вопросам. Зачем: длинный поиск и логи не забивают основную беседу, каждый занят своим. Ваша роль меняется: не писать код, а поставить цель, утвердить план и проверить результат. Вопрос группе: «Яку частину вашої роботи ви б віддали окремому помічнику: пошук, перевірку чи тести?»

AXAL · Заняття 3 · за документацією Claude Code: permission modes, листопад 2026

Важно: в их веб-Code (облачные сессии) в списке три режима: Accept edits, Plan, Auto. Manual есть только в приложении на компьютере и в терминале. В облаке правки файлов разрешены всегда, поэтому Accept edits там и есть «обычный» режим. Plan: читает, может запускать команды для изучения, но не правит, пока план не утверждён; при утверждении выбираете, в каком режиме продолжать. Auto: отдельная модель проверяет каждое действие и блокирует то, что выходит за рамки запроса; Claude реже останавливается на вопросы. Сказать: «Нова задача — завжди з Plan». Показ — следующий: задача с CSV сразу в режиме Plan.

AXAL · Заняття 3 · за документацією Claude Code: memory

Ответ на частый вопрос. CLAUDE.md в корне читается в каждой сессии целиком — Anthropic советует держать до 200 строк, иначе Claude хуже следует правилам. CLAUDE.md во вложенной папке подгружается только когда Claude читает или правит файлы в этой папке — туда кладут особенности конкретной автоматизации, и то если они есть. Процедуры — в skills. Реестр (у них AUTOMATIONS.md) — обязательно, это ответ на «где код и кто владелец». Их рабочий CLAUDE.md около 25 КБ — это примерно в 3–4 раза длиннее рекомендации; без подробностей содержимого.
