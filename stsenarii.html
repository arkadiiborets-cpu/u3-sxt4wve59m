Хмарна задача чи задача в додатку на комп'ютері?Облачная работает, даже когда компьютер выключен, раз в час или реже. В приложении — на вашем компьютере, чаще, но только пока он включён.
Чи бачать колеги мої skills і задачі?Аккаунт общий — да, видят все. Поэтому в названии фамилия.
Що якщо Claude поставить cron не на той час?Спросить: «покажи рядок розкладу і наступний запуск за Києвом». Cron на сервере считает время по UTC: 9:05 по Киеву зимой — 7:05 UTC.
Скільки skills можна мати?Много: заранее Claude читает только названия и описания. Мешают не skills, а длинный CLAUDE.md.
Чому мій skill не спрацював?Почти всегда описание: в нём должны быть слова, которыми вы сами просите. Проверять в новой сессии, не называя skill.
Що таке репозиторій простими словами?Общая папка на GitHub с историей изменений. Code работает прямо в ней, и всё, что там лежит, видит следующая сессия.
n8n чи Claude?Следующее занятие. n8n, Make, Zapier — когда надо соединить сервисы готовыми блоками. Claude — когда надо понять текст или принять решение.
Як зробити, щоб бот писав у групу?Добавить бота в группу, написать там что угодно и сказать Claude — он найдёт номер группы.
Codex чи Claude Code — у чому різниця?Похожие агенты. Принципы те же: контекст, инструкции, проверка результата. Мы работаем в Claude, потому что вся ваша система уже на нём.

Если что-то не так

Тишина

Вызвать по имени (вопросы с именем выше). Или опрос реакциями Meet: «👍 — так, 👎 — ні». Или «Напишіть у чат одне слово».

Claude думает

Не молчать. «Поки Claude працює: що ви перевірите першим у його відповіді?», «Як би ви зробили це без Claude і скільки б це зайняло?», «Хто вже робив щось схоже?»

Claude ошибся

Это лучший момент урока. Спросить группу: «Що тут не так? Як би ви це помітили, якби не дивились?» Потом поправить skill вслух.

Code не открылся

Показывать в обычном чате: «збережи як skill» → Claude пишет SKILL.md. Файлы skills показать на GitHub: .claude/skills.

Лимит кончился

Перейти на свой аккаунт Claude, репозиторий тот же.

Отстаю на 10+ мин

Резать по порядку: слайд 12, чат в показе 1, слайд 22 до одного случая, квиз до 4 пунктов, показ расписания до показа страницы. Домашку и вопросы не резать.
